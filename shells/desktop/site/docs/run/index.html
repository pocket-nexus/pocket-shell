Build and run

One resolved System across three hosts.

The host changes by target. The System manifest, System UI package and installed app catalog do not.

Setup

Install Bun and stable Rust. Clone submodules before building:

$ git clone --recurse-submodules https://github.com/pocket-nexus/pocket-shell.git
$ cd pocket-shell
$ bun run setup
$ bun run desktop check

macOS

Xcode command-line tools provide the native toolchain. The first command creates a release build; the second launches it.

$ bun run desktop build
$ bun run desktop macos

Linux

The Linux host needs the X11/Wayland and software presentation development libraries listed in CI. The package command emits a relocatable product directory and pocket-desktop-linux-<arch>.tar.gz.

$ bun run desktop package:linux
$ tar -xzf shells/desktop/dist/linux-app/pocket-desktop-linux-*.tar.gz
$ ./PocketDesktop/bin/pocket-desktop

The launcher resolves its own installation directory, sets the artifact root and gives the host the complete resolved System plan.

WebAssembly

The browser preview runs the System UI and every installed app through PocketJS's WASM engine. Each app uses an independent iframe Realm and UI instance.

$ bun run desktop build:web
$ bun run desktop web
# open http://127.0.0.1:4173

Open the deployed preview →

Validation

$ bun run desktop check
$ bun run desktop test:web
$ bun run desktop test:site

test:web drives a real headless Chrome session, double-clicks Hero and waits for the child raster to replace the System UI fallback.
