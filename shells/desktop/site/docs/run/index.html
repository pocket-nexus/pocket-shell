Build and run

Build the browser preview and embedded interface.

The browser preview resolves its installed app catalog. A Studio product supplies its own host contract and application services.

Setup

Install the Bun version from .bun-version and the Rust toolchain from vendor/pocketjs/rust-toolchain.toml, including wasm32-unknown-unknown. Clone submodules before building:

$ git clone --recurse-submodules https://github.com/pocket-nexus/pocket-shell.git
$ cd pocket-shell
$ bun run setup
$ bun run desktop check

Studio computer

The embedding product owns the display and input. Compile shells/desktop/pocket.app.studio.json against that product's pocket.host.json. Run the package through PocketJS's shared runtime and provide the system-ui and pocket-studio services. The shell draws the desktop and themes into the product's screen target.

See the embedding commands.

WebAssembly

The browser preview runs the System UI and every installed app through PocketJS's WASM engine. Each app uses an independent iframe Realm and UI instance.

$ bun run desktop build:web
$ bun run desktop web
# open http://127.0.0.1:4173

Open the deployed preview →

Validation

$ bun run desktop check
$ bun run desktop test:web
$ bun run desktop build:site
$ bun run desktop test:site

test:web drives a real headless Chrome session, double-clicks Hero and waits for the child raster to replace the System UI fallback.
