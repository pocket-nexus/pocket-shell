Contributing

Contribute to the desktop shell.

Pocket Shell Desktop accepts code, documentation and original theme assets under GNU GPL version 3 only, within the Pocket Shell repository.

Workflow

Open an issue before substantial product, protocol or theme work. Pull requests use Conventional Commit titles and must pass the native, Linux distribution and WebAssembly preview checks.

$ bun run setup
$ bun run desktop check
$ bun run desktop build

Licensing

This desktop shell is distributed under GNU GPL version 3 only. Read the GPLv3 terms and the repository contribution rules. Contributors retain copyright and preserve the applicable GPL notices.

Third-party assets

Do not import icons, fonts or theme graphics without recording provenance and license terms. Original project assets and independently implemented drawing code are preferred. Existing third-party notices are maintained in THIRD_PARTY.md.
